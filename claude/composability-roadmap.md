# Composability Roadmap — сборка сценариев из блоков (ВЕСЬ ПРОЕКТ)

Статус: ЗАКРЫТА (Ш16 — финал инициативы). Владелец: Davlat.
Журнал: claude/composability-journal.md.
Карты: claude/retail-navigation-map.md, claude/agro-navigation-map.md.

## Охват: весь проект (розница + Агро/Микро)
Розницу прошли первой как эталонный хребет; Агро/Микро — своим треком; крупные сквозные
рефакторинги (Ш15) шли на весь проект.

## Цель (достигнута)
- авторизация; заёмщик+залогодатель; упрощённый с поручителем/залогодателем/залогами;
  стандартный без участников/залогов;
- документы участника на «Сборе документов» предрешены флагом, а не статическим списком;
- минимум «проваливания» вглубь; оценка и снятие хардкода; неотделимые процессы — единым блоком.

## Принятые решения (развилки)
1. Документы участника: резолвер «роль→документы» + флаг `attachDocuments` на ParticipantData
   (розница true; withoutDocuments() — off). Реализовано: ParticipantDocuments.
2. Модель маршрута: именованные standard/simplified/runFull + scenario-driven внутри.
3. Порядок: проход по процессу auth→завершение, карта наполнялась параллельно.

## Правила процесса
Одно решение → подтверждение → один шаг. Локаторы/UI-текст только по live DOM. test-compile
после каждого изменения. Рабочий код не трогаем без живого прогона; E2E — в контрольных точках.
Документируй при изменении. Allure-метки обязательны (AllureTags).
